# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 受控发布线
功能开关、发布计划、依赖开关和审计记录串成一条受控发布线：

- **候选发布**：每次提交把当前草稿（规则 + 放量）固化成带版本号和内容哈希的候选发布；旧候选随即作废，审批需重新进行。
- **审批绑定内容**：产品/研发双审批只认可该次提交的内容哈希，后续再提交会使旧审批随之失效。
- **定时切换**：到点先核对依赖开关仍然启用、审批仍然有效，两项都满足才一次性切到新规则和放量比例，并记下生效时间。
- **失败留待处理**：任一核对不通过则保持原生效版本不动，本次发布标记为待处理，可修复后重试或重新定时。
- **紧急停止**：立即停用开关，并同时作废生效中与待生效的发布，避免与定时切换撞单。
- **回滚**：恢复上一个生效过的版本。
- **三态可辨**：页面清晰区分正在生效、等待生效（含待处理）和已经作废的版本；命中模拟始终按正在生效的版本计算。

## 已实现闭环
- 功能开关、候选发布、依赖开关、审计记录四类业务对象。
- 规则组合、模拟用户命中、逐步调整流量和定时生效。
- 产品/研发双审批、版本化候选发布、定时自动切换、失败待处理、紧急停止、回滚。
- 离线提示、VeeValidate + Zod 精确校验和 localStorage 持久化。
